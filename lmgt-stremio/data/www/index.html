Stremio Server

This is the local Stremio streaming server. Use a Stremio client to browse and play. This page is only for connection details.

Streaming server URL

In the Stremio app: Settings → Streaming → enable override, then paste:

http://umbrel.local:11470

HTTPS (self-signed) is also available at https://umbrel.local:12470.

What this server can play

Play torrents from Stremio addons (for example Stremio Jackett). The file is downloaded on the Umbrel.

A video file on your Mac or phone is not on the Umbrel. The server will log Cannot parse path and fail. For local files, turn off the streaming-server override in Stremio so the app uses its own local server.

Use with Stremio Jackett

  1. Install Jackett from the official Umbrel App Store and add your indexers. Copy the Jackett API key.
  2. Optional: install Flaresolverr from the official store. In Jackett, set FlareSolverr to http://flaresolverr_server_1:8191.
  3. Install Stremio Jackett from this community store. Open it and set Jackett URL to http://jackett_server_1:9117 plus your API key, then install the addon into Stremio.

Stremio clients connect to ports 11470 and 12470 on this device. Those ports are not behind Umbrel login. Keep the server running while you watch.
